# Quickstart

Create your `.env`. You can refer keys in `.env.example`
```bash
cp .env.example .env
```

Installation
```bash
npm run install
```

For dev
```bash
npm run dev
```

For build
```bash
npm run build
```

Using docker
```bash
docker compose up -d
```
